# deepfakeface
Deep learning discriminative and generative models, applied to the  context of “deep fakes”. The discriminative models will be designed to classify images as “real” vs. “fake”,  whereas the generative models will be trained to produce new “fake” examples.



# Classifier
1. Transformer
2. NN
3. YOLO
4. multilayer perceptrons

# Generative
1. GAN
2. Autoencoders
3. Diffusion models
